## 6. ข้อกำหนดระบบ Guestbook & Private Messaging (Guestbook System Specification)

ระบบสมุดเยี่ยมชม (Guestbook) ออกแบบมาเพื่อให้ผู้เข้าชม (Recruiters, เพื่อนร่วมงาน, เพื่อนสนิท) สามารถเขียนคำนิยม (Peer Recommendation), ทักทาย หรือฝากข้อความส่วนตัวถึงเจ้าของเว็บได้ โดยเจ้าของเว็บมีอำนาจในการควบคุม (Moderation) ข้อความทั้งหมด 100%

### 1) มุมมองผู้ใช้งานทั่วไป (Visitor Features)
- **แบบฟอร์มการส่งข้อความ (Message Form)**:
  - **ชื่อผู้ส่ง (Sender Name)**: ระบุชื่อเล่นหรือชื่อจริง (Required)
  - **ความสัมพันธ์/บทบาท (Role/Relationship)**: เช่น *"อดีตเพื่อนร่วมงาน @ Company X"*, *"Recruiter"*, *"เพื่อน มช. CS รุ่น 45"* (Optional)
  - **อีเมล / ช่องทางติดต่อ (Contact Info)**: ข้อมูลนี้จะถูกเก็บเป็นความลับ (Owner Only) ไม่แสดงหน้าเว็บ (Optional)
  - **ข้อความ (Message)**: รองรับความยาวสูงสุด 500 ตัวอักษร
  - **ตัวเลือกระดับความเป็นส่วนตัว (Visibility Option)**:
    - 🌐 **"ขอแสดงบนหน้าเว็บ (Public Comment)"**: ข้อความจะเข้าสู่สถานะ `Pending Review` เพื่อรอเจ้าของเว็บกดอนุมัติก่อนขึ้นหน้าเว็บ
    - 🔒 **"ข้อความลับถึงคุณเชาวน์เท่านั้น (Private Message)"**: ข้อความจะเข้าสู่สถานะ `Private` ซึ่งจะมีเพียงเจ้าของเว็บที่มองเห็น
- **ระบบป้องกันสแปม (Anti-Spam & Security)**:
  - ใช้ **CAPTCHA** (เช่น Google reCAPTCHA หรือ Cloudflare Turnstile) เพื่อยืนยันตัวตนผู้ส่งและป้องกัน bot spam ได้อย่างมีประสิทธิภาพและเรียบง่าย

---

### 2) มุมมองและการควบคุมของเจ้าของเว็บ (Owner / Admin Moderation Panel)
- **ระบบการเข้าถึงของผู้ดูแล (Admin Access)**:
  - ซ่อนปุ่ม Admin Login ในส่วน Footer หรือเข้าผ่าน URL เฉพาะ เช่น `/admin` หรือ `?admin=login`
  - ยืนยันตัวตนด้วย **Admin Secret PIN / Passcode** หรือ Passwordless Token (Magic Link)
- **แดชบอร์ดจัดการข้อความ (Moderation Actions)**:
  - 📥 **Inbox Tab**: ดูข้อความใหม่ทั้งหมด แบ่งตามหมวด (`Pending Review`, `Private Messages`, `Approved`)
  - 🔘 **ปุ่มการกระทำ (Action Buttons)**:
    - `[✅ Approve & Publish]`: อนุมัติข้อความให้ออกสู่หน้าเว็บทันที
    - `[🔒 Keep Private]`: เก็บเป็นข้อความส่วนตัว ไม่ให้แสดงบนหน้าเว็บ
    - `[📌 Pin to Top]`: ปักหมุดข้อความคำชมเด่นไว้บนสุดของ Wall of Love
    - `[🗑️ Delete / Mark as Spam]`: ลบข้อความที่ไม่เหมาะสมออก
- **ระบบแจ้งเตือนเจ้าของเว็บ (Instant Notification)**:
  - ส่งการแจ้งเตือนทันทีเมื่อมีข้อความใหม่ผ่าน **Telegram Bot** หรือ **Discord Webhook** หรือ **Email Notification (Resend API)**

### 3) โครงสร้างฐานข้อมูล (Database Schema)

```sql
CREATE TABLE guestbook_messages (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    sender_name VARCHAR(100) NOT NULL,
    sender_role VARCHAR(150),
    sender_email VARCHAR(255),
    message_content TEXT NOT NULL,
    is_private BOOLEAN DEFAULT FALSE,
    status VARCHAR(20) DEFAULT 'pending', -- 'pending', 'approved', 'rejected', 'private'
    is_pinned BOOLEAN DEFAULT FALSE,
    client_ip VARCHAR(50),
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    approved_at TIMESTAMP WITH TIME ZONE
);
```

## 7. สถาปัตยกรรมและเทคโนโลยีที่เลือกใช้ (Technical Stack & Architecture Decision)

### 🏗️ สถาปัตยกรรมระบบ (System Architecture)
เลือกใช้แนวทาง **Full-stack Serverless / Zero-Ops** ด้วย **Next.js + Supabase บน Vercel** โดย**ไม่จำเป็นต้องทำ Backend แยก** (ประหยัดค่าใช้จ่าย 100%, ไร้ภาระการดูแลเซิร์ฟเวอร์ และได้ Type Safety แบบ End-to-End)

```
[ ผู้ใช้งาน / Recruiters ]
           │
           ▼
[ Vercel Edge / Global CDN ]
           │
  ┌────────┴─────────────────────────────────────────┐
  │  Next.js (App Router + TypeScript)               │
  │  ├─ UI: React + Tailwind CSS + shadcn/ui         │
  │  ├─ Motion & Icons: Framer Motion + Lucide Icons │
  │  ├─ Rendering: SSG / ISR (โหลดไวระดับเสี้ยววิ)    │
  │  └─ Server Actions (Serverless API Logic)        │
  └────────┬────────────────────────────────┬────────┘
           │ (บันทึก / ดึงข้อมูล Guestbook)       │ (ส่งแจ้งเตือนทันที)
           ▼                                ▼
[ Supabase (PostgreSQL + RLS) ]    [ Telegram Bot / Discord Webhook ]
```

---

### 💻 รายละเอียด Tech Stack (100% Free-Tier Architecture)

| ส่วนประกอบ | เทคโนโลยี / บริการ | รายละเอียดและหน้าที่ | ค่าใช้จ่าย |
| :--- | :--- | :--- | :--- |
| **Core Framework** | **Next.js (App Router)** | Full-stack React Framework รองรับ SSG/ISR และ Server Actions | ฟรี |
| **Language** | **TypeScript** | Type Safety ตลอดทั้งแอปพลิเคชัน | ฟรี |
| **Styling & UI** | **Tailwind CSS + shadcn/ui** | ดีไซน์ UI เรียบหรู Minimal สไตล์ Senior Engineer รองรับ Dark/Light Mode | ฟรี |
| **Animation & Icons**| **Framer Motion + Lucide Icons** | Micro-interactions, Smooth Scrolling และชุดไอคอนคมชัด | ฟรี |
| **Backend & Server Logic** | **Next.js Server Actions** | จัดการ Business Logic และเชื่อมต่อ DB โดยตรง (ไม่ต้องแยก Backend Server) | ฟรี |
| **Database** | **Supabase (PostgreSQL)** | ฐานข้อมูล Cloud PostgreSQL พร้อม Row Level Security (RLS) | ฟรี (Free Tier) |
| **Anti-Spam** | **Cloudflare Turnstile** | ระบบยืนยันตัวตนกันสแปมแบบ Frictionless หน้าฟอร์ม Guestbook | ฟรี |
| **Notifications** | **Telegram Bot / Discord Webhook** | ยิงแจ้งเตือนเข้ามือถือทันทีเมื่อมีข้อความใหม่ (Public / Private) | ฟรี |
| **Hosting & CI/CD** | **Vercel** | เชื่อม GitHub Auto-deploy พร้อม Global CDN และ SSL/HTTPS อัตโนมัติ | ฟรี (Hobby Tier) |

### 🌟 ฟีเจอร์หลักของระบบ (Key Features)
1. **Responsive & Mobile-First**: รองรับการแสดงผลทุกขนาดหน้าจอ 100%
2. **Dark / Light Mode Toggle**: สลับธีมมืดและสว่างอย่างสมบูรณ์แบบ
3. **Interactive Portfolio**: กรองดูโปรเจกต์ (Project Filtering) และทักษะ (Skill Matrix)
4. **Guestbook & Private Messaging**:
   - ระบบฝากคำนิยม (Public Testimonials) รอการอนุมัติ
   - ระบบข้อความลับ (Private Messages) ถึงเจ้าของเว็บโดยตรง
5. **Owner Admin Moderation Dashboard (`/admin`)**:
   - ตรวจสอบข้อความใหม่, กด Approve/Pin/Delete หรือเก็บเป็น Private
   - ป้องกันสิทธิ์ด้วย Admin Passcode / Secure Session
6. **Print-Ready / PDF Export**: จัด Layout สวยงามสำหรับสั่งพิมพ์หรือบันทึกเป็น PDF Resume
7. **SEO & OpenGraph Metadata**: พร้อมแชร์บน LinkedIn, Facebook, Twitter อย่างมืออาชีพ
